## 使用规则

- 归档文档用于追溯历史结论、阶段封板和旧结构，不用于判断当前系统真相。
- 若归档内容与 `00-foundation/`、`01-status/`、`02-architecture/`、`03-protocol/` 冲突，以活跃文档为准。
- 新的历史留痕优先进入 ADR 或归档区，不回流到活跃主文档中。
